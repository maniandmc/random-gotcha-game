# ✨ 운명의 소환 — 랜덤 가챠 게임

설치 없이 브라우저에서 바로 돌아가는 가챠(뽑기) 게임입니다. HTML·CSS·JavaScript만 사용합니다.

## 실행 방법

`index.html`을 더블클릭해 브라우저로 열면 끝입니다.

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## 기능

- 1회 / 10회 소환 (10회는 SR 이상 1개 확정)
- 천장: 60번째 소환은 SSR 확정, 게이지로 남은 횟수 표시
- 빛 구슬 색으로 최고 등급을 미리 보여주는 연출 + 카드 뒤집기
- 도감(수집 현황), 소환 기록, 확률 공개표(내 실제 결과와 비교)
- 진행 상황 자동 저장 (브라우저 localStorage)

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/data.js` | **확률, 캐릭터, 가격, 천장 횟수** 설정. 대부분의 수정은 여기서 합니다 |
| `js/gacha.js` | 뽑기 핵심 로직 (가중치 랜덤, 천장, 10회 보장). 화면과 분리돼 있습니다 |
| `js/main.js` | 화면 그리기, 버튼 이벤트, 저장/불러오기 |
| `style.css` | 디자인 |
| `tools/simulate.js` | 확률이 의도대로 나오는지 대량으로 뽑아보는 검증 스크립트 |

## 커스터마이징

**캐릭터 추가**: `js/data.js`의 `CHARACTERS`에 한 줄 추가합니다. `id`는 겹치면 안 됩니다.

```js
{ id: 'penguin', name: '펭귄 대장', emoji: '🐧', rarity: 'SR' },
```

**확률 변경**: `RARITIES`의 `weight`를 바꿉니다. 같은 등급의 캐릭터끼리는 확률을 똑같이 나눠 갖습니다.

수정한 뒤에는 검증 스크립트를 돌려보세요 (Node.js 필요):

```bash
node tools/simulate.js          # 10만 회 소환 시뮬레이션
```

## 핵심 원리

1. **가중치 랜덤**: 0~100 사이 난수를 뽑아 `0~82 → R`, `82~97 → SR`, `97~100 → SSR`처럼 구간으로 등급을 정합니다 (`weightedPick`).
2. **천장(pity)**: SSR 없이 뽑은 횟수를 세다가 60번째에 SSR을 강제로 줍니다. SSR이 나오면 0으로 초기화됩니다.
3. **10회 보장**: 앞의 9장에 SR 이상이 없으면 마지막 1장은 SR·SSR 중에서만 뽑습니다.
4. 등급을 먼저 정하고, 그 등급 안에서 캐릭터를 균등하게 고릅니다.

천장과 10회 보장 때문에 실제 SSR 비율은 표시 확률(3%)보다 조금 높게(약 3.6~3.8%) 나옵니다.

## 다음 단계 아이디어

- **픽업 배너**: SSR이 나오면 50% 확률로 픽업 캐릭터, 빗나가면 다음 SSR은 픽업 확정
- **소프트 천장**: 50회 이후부터 SSR 확률이 점점 오르는 방식
- 이모지 대신 캐릭터 일러스트, 효과음 추가
- 중복 캐릭터를 강화 재료로 쓰는 성장 시스템
- **서버 추첨**: 지금은 브라우저에서 추첨하므로 개발자 도구로 결과를 조작할 수 있습니다. 실제 서비스라면 추첨과 재화 관리를 서버에서 해야 합니다
